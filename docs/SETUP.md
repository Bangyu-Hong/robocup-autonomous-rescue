## 环境与运行

### MCU 工程

使用 Keil MDK 打开 [test1.uvprojx](../src/stm32f407-chassis/MDK-ARM/test1.uvprojx)。对应 STM32CubeMX 配置见 [test1.ioc](../src/stm32f407-chassis/test1.ioc)。

使用前按实物核对晶振、芯片型号、引脚、轮径、轮距、编码器分辨率与四轮方向。保存目录名包含“8M”，编译环境与时钟配置仍以工程文件和硬件为准；本次没有执行编译或烧录。

主目录 `main.c` 中保存的轮位映射为：

| 通道 | 位置 |
|---|---|
| A | 左前 LF |
| B | 右前 RF |
| C | 左后 LR |
| D | 右后 RR |

历史 `compare-main.c` 中 B / C 分别对应左后 / 右前，角速度计算也不同。原有说明文档部分内容沿用历史轮序，接线及参数须以实际硬件与选用代码核对。

### 串口与 ROS 接口

| 方向 | 格式 | 含义 |
|---|---|---|
| 上位机 → 底盘 | `$vx,vy,wz\r\n` | 前向、横向线速度（m/s）及角速度（rad/s） |
| 底盘 → 上位机 | `$x,y,th,vx,vy,wz\r\n` | 位姿及车体速度 |

保存工程使用 ROS 串口与 IMU 串口，原有说明中的默认波特率为 `115200`。按所选输出模式核对正常数据与调试信息，具体见[通信协议](../src/stm32f407-chassis/PROTOCOL_GUIDE.md)。

原说明包含 ROS 通信节点示例，但当前仓库未提供对应整机的完整上位机工作空间，因此不提供未经核对的一键 SLAM / 导航启动命令。
