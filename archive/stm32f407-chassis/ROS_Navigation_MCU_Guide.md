## 五、里程计计算原理

### 5.1 每脉冲距离计算

```
轮子周长 = π × 直径 = 3.14159 × 0.095m = 0.2985m

每转脉冲数 = 编码器线数 × 4倍频 × 减速比
           = 13 × 4 × 30 = 1560 脉冲/转

每脉冲距离 = 轮子周长 ÷ 每转脉冲数
           = 0.2985m ÷ 1560
           = 0.000191m ≈ 0.19mm
```

### 5.2 麦克纳姆轮正运动学

```
机器人速度计算:

vx = (v_fl + v_fr + v_rl + v_rr) / 4        // 前进速度
vy = (-v_fl + v_fr + v_rl - v_rr) / 4       // 侧移速度
wz = (-v_fl + v_fr - v_rl + v_rr) / (4×L)   // 角速度

其中: L = (轮距 + 轴距) / 2 = 0.19m
```

### 5.3 全局坐标转换

```c
// 局部坐标 → 全局坐标
vx_global = vx_local × cos(th) - vy_local × sin(th)
vy_global = vx_local × sin(th) + vy_local × cos(th)

// 位置积分
x += vx_global × dt
y += vy_global × dt
th += wz × dt
```

## 九、中断优先级说明

当前配置的中断优先级（数字越小优先级越高）：

```
优先级 0: TIM7 (PID控制)    ← 最高，绝对不能被打断
优先级 1: TIM2/3/4/8 (编码器溢出)
优先级 2: USART2 (IMU数据)
优先级 3: USART1 (ROS通信)
优先级 4: DMA (数据传输)    ← 最低
```

**设计原则**:
- PID控制必须准时执行（100Hz），不能被任何中断打断
- 编码器溢出需要及时处理，否则计数会出错
- 通信可以稍微延迟，不影响控制精度
