# 自动捡球小车 - 参数调整指南

本文档列出了所有需要根据实际硬件测量和调试的参数。

## 一、必须测量的物理参数

### 1.1 机械结构参数 (`src/kinematics.h`)

| 参数 | 当前值 | 单位 | 测量方法 |
|------|--------|------|----------|
| `WHEEL_RADIUS` | 0.0385 | 米 | 用卡尺测量轮子直径，除以2 |
| `WHEEL_TRACK` | 0.1500 | 米 | 测量左轮中心到右轮中心的距离 |
| `WHEEL_BASE` | 0.1200 | 米 | 测量前轮轴中心到后轮轴中心的距离 |

```c
// 文件: src/kinematics.h 第10-13行
#define WHEEL_RADIUS      0.0385f   // 修改为你的轮子半径
#define WHEEL_TRACK       0.1500f   // 修改为你的左右轮距
#define WHEEL_BASE        0.1200f   // 修改为你的前后轴距
```

### 1.2 编码器与电机参数 (`src/kinematics.h`)

| 参数 | 当前值 | 说明 | 获取方法 |
|------|--------|------|----------|
| `ENCODER_PPR` | 11 | 编码器每转脉冲数 | 查看电机规格书 |
| `GEAR_RATIO` | 30 | 减速比 | 查看电机规格书 |
| `ENCODER_MODE` | 4 | 4倍频计数 | 通常固定为4 |

```c
// 文件: src/kinematics.h 第15-18行
#define ENCODER_PPR       11        // 编码器线数 (查电机规格书)
#define GEAR_RATIO        30        // 减速比 (查电机规格书)
#define ENCODER_MODE      4         // 4倍频计数 (通常不改)
```

**常见电机编码器参数参考：**
- JGA25-370电机: PPR=11, 减速比=30/50/100
- GB37电机: PPR=11, 减速比=30
- N20电机: PPR=7, 减速比=30/50/100

## 二、需要调试的控制参数

### 2.1 PID参数 (`src/hal_entry.c`)

| 参数 | 当前值 | 建议范围 | 说明 |
|------|--------|----------|------|
| `my_Kp` | 30.0 | 10~100 | 比例系数，控制响应速度 |
| `my_Ki` | 2.0 | 0.5~10 | 积分系数，消除稳态误差 |
| `my_Kd` | 0.0 | 0~5 | 微分系数，抑制超调 |

```c
// 文件: src/hal_entry.c 第143-146行
float my_Kp = 30.0f;   // 比例系数
float my_Ki = 2.0f;    // 积分系数
float my_Kd = 0.0f;    // 微分系数
```

**PID调试步骤：**
1. 先设置 `Ki=0, Kd=0`，只调 `Kp`
2. 逐渐增大 `Kp`，直到电机出现轻微震荡
3. 将 `Kp` 减小到震荡消失
4. 逐渐增大 `Ki`，直到稳态误差消除
5. 如果有超调，适当增大 `Kd`

### 2.2 电机死区补偿 (`src/motor.c`)

| 参数 | 当前值 | 建议范围 | 说明 |
|------|--------|----------|------|
| `MOTOR_DEAD_ZONE` | 1500 | 1000~3000 | PWM死区值 |

```c
// 文件: src/motor.c 第24行
#define MOTOR_DEAD_ZONE   1500   // PWM死区值
```

**测试方法：**
1. 写一个测试程序，PWM从0逐渐增加
2. 记录电机刚开始转动时的PWM值
3. 将该值设为 `MOTOR_DEAD_ZONE`

### 2.3 速度滤波系数 (`src/hal_entry.c`)

| 参数 | 当前值 | 建议范围 | 说明 |
|------|--------|----------|------|
| `FILTER_COEFF` | 0.7 | 0.5~0.9 | 越大越平滑，但响应越慢 |

```c
// 文件: src/hal_entry.c 第257行
#define FILTER_COEFF 0.7f
```

## 三、麦轮布局说明

当前代码适用于 **X型麦轮布局（滚轴朝外）**：

```
        前进方向
           ↑
     A ╲      ╱ C
       ╲    ╱
        ╲  ╱
         ╲╱
         ╱╲
        ╱  ╲
       ╱    ╲
     B ╱      ╲ D
```

- A = 左前轮 (MOTOR_A_LF)
- B = 左后轮 (MOTOR_B_LR)
- C = 右前轮 (MOTOR_C_RF)
- D = 右后轮 (MOTOR_D_RR)

**如果你的麦轮布局是O型（滚轴朝内），需要修改运动学公式！**

## 四、编码器方向校准

### 4.1 检查方法

1. 让每个轮子单独正转（向前）
2. 观察编码器计数是否增加
3. 如果减少，需要在代码中取反

### 4.2 当前取反设置 (`src/hal_entry.c`)

```c
// 文件: src/hal_entry.c 第241-244行
count_A = (int16_t)status_A.counter;        // 左前不取反
count_B = (int16_t)status_B.counter;        // 左后不取反
count_C = -(int16_t)status_C.counter;       // 右前取反
count_D = -(int16_t)status_D.counter;       // 右后取反
```

根据你的实际安装情况，可能需要调整取反的轮子。

## 五、ROS通信配置

### 5.1 启用ROS串口

取消以下代码的注释（`src/hal_entry.c` 第134-137行）：

```c
R_SCI_UART_Open(&g_uart_ros_ctrl, &g_uart_ros_cfg);
uint8_t dummy_rx;
R_SCI_UART_Read(&g_uart_ros_ctrl, &dummy_rx, 1);
```

### 5.2 通信协议

**接收命令格式：** `$vx,vy,wz\n`
- vx: 前进速度 (m/s)
- vy: 横移速度 (m/s)
- wz: 旋转角速度 (rad/s)

**发送数据格式：** `$x,y,yaw,vx,vy,wz\r\n`
- x, y: 里程计位置 (m)
- yaw: 航向角 (rad)
- vx, vy, wz: 当前速度

## 七、常见问题

### Q1: 小车走不直
- 检查四个轮子的PID参数是否需要单独调整
- 检查编码器计数方向是否正确
- 检查轮子安装是否对称

### Q2: 速度响应太慢
- 增大PID的Kp值
- 减小滤波系数 `FILTER_COEFF`

### Q3: 电机有噪音/震荡
- 减小PID的Kp值
- 增加滤波系数 `FILTER_COEFF`

### Q4: 里程计漂移严重
- 检查物理参数测量是否准确
- 确认使用IMU的yaw角度而不是积分

## 八、参数计算器

### 速度转换系数验证

如果你的参数是：
- 编码器线数: 11 PPR
- 减速比: 30
- 轮子半径: 0.0385m
- 控制周期: 10ms

则：
```
每转脉冲数 = 11 × 30 × 4 = 1320 脉冲/转
轮子周长 = 2 × π × 0.0385 = 0.242m

PULSE_TO_MPS = 0.242 / 1320 / 0.01 = 0.0183 (m/s per pulse/10ms)
MPS_TO_PULSE = 1 / 0.0183 = 54.6 (pulse/10ms per m/s)
```

这些值会由代码自动计算，你只需要正确填写基础参数即可。
