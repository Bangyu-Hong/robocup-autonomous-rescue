## 1. 系统概览

### 1.1 硬件清单

| 序号 | 元件 | 数量 | 说明 |
|------|------|------|------|
| 1 | STM32F407开发板 | 1 | 主控制器 |
| 2 | 直流减速电机 | 4 | 带编码器，13线，30减速比 |
| 3 | TB6612/L298N电机驱动 | 2-4 | 双H桥驱动 |
| 4 | WT901BCTTL IMU | 1 | 九轴姿态传感器 |
| 5 | 麦克纳姆轮 | 4 | 95mm直径 |
| 6 | 电源模块 | 1 | 12V电机供电 + 5V/3.3V逻辑供电 |

### 1.2 轮子布局定义

```
            前方 (X+)
              ↑
    ┌─────────┴─────────┐
    │                   │
    │  [A]         [C]  │
    │  左前        右前  │
    │  (LF)       (RF)  │
    │                   │
    │  [B]         [D]  │
    │  左后        右后  │
    │  (LR)       (RR)  │
    │                   │
    └───────────────────┘

    轮子代号对照:
    A = 左前 (Left Front)   - 电机A
    B = 左后 (Left Rear)    - 电机B
    C = 右前 (Right Front)  - 电机C
    D = 右后 (Right Rear)   - 电机D
```

## 3. 编码器接线

### 3.1 编码器引脚定义

电机编码器通常为6线制：

| 线色(参考) | 功能 | 说明 |
|------------|------|------|
| 红 | VCC | 编码器电源 (5V) |
| 黑 | GND | 编码器地 |
| 黄 | A相 | 编码器输出A (CH1) |
| 绿 | B相 | 编码器输出B (CH2) |
| 蓝 | M+ | 电机正极 |
| 白 | M- | 电机负极 |

> ⚠️ **注意**: 实际线色可能因厂家不同而异，请以实物标注为准！

## 4. 串口通信接线

### 4.1 USART1 - ROS通信

用于与ROS上位机通信（速度指令接收/里程计发送）

| STM32引脚 | 功能 | 连接目标 | 说明 |
|-----------|------|----------|------|
| **PA9** | USART1_TX | USB转TTL RX | STM32发送 → 上位机接收 |
| **PA10** | USART1_RX | USB转TTL TX | 上位机发送 → STM32接收 |
| **GND** | 地 | USB转TTL GND | 共地 |

**通信参数**: 115200bps, 8N1

```
┌─────────────────┐          ┌─────────────────┐
│   STM32F407     │          │   USB转TTL      │
│                 │          │                 │
│  PA9 (TX) ──────┼──────────┼─► RX            │
│  PA10(RX) ◄─────┼──────────┼── TX            │
│  GND ───────────┼──────────┼── GND           │
│                 │          │                 │
└─────────────────┘          └─────────────────┘
                                    │
                                    │ USB
                                    ▼
                             ┌─────────────┐
                             │  ROS 上位机  │
                             └─────────────┘
```

### 4.2 USART2 - IMU通信

用于接收WT901BCTTL IMU数据

| STM32引脚 | 功能 | 连接目标 | 说明 |
|-----------|------|----------|------|
| **PA2** | USART2_TX | IMU RX | (可选，用于配置IMU) |
| **PA3** | USART2_RX | IMU TX | IMU发送 → STM32接收 |
| **GND** | 地 | IMU GND | 共地 |
| **5V/3.3V** | 电源 | IMU VCC | IMU供电 |

**通信参数**: 115200bps, 8N1

```
┌─────────────────┐          ┌─────────────────┐
│   STM32F407     │          │  WT901BCTTL     │
│                 │          │                 │
│  PA2 (TX) ──────┼──────────┼─► RX (可选)     │
│  PA3 (RX) ◄─────┼──────────┼── TX            │
│  GND ───────────┼──────────┼── GND           │
│  5V ────────────┼──────────┼── VCC           │
│                 │          │                 │
└─────────────────┘          └─────────────────┘
```

## 7. 接线注意事项

### 7.1 电源注意事项

| ⚠️ 警告 | 说明 |
|---------|------|
| **共地** | 所有模块的GND必须连接在一起 |
| **电压匹配** | STM32为3.3V系统，接5V信号需加电平转换 |
| **电流容量** | 电机驱动电源需足够的电流能力 |
| **隔离供电** | 建议电机电源与逻辑电源隔离 |

### 7.2 信号线注意事项

| ⚠️ 注意 | 说明 |
|---------|------|
| **编码器信号** | 尽量使用屏蔽线，远离电机驱动线 |
| **PWM线** | 不宜过长，避免信号衰减 |
| **串口线** | TX接RX，RX接TX (交叉连接) |
| **接地** | 信号线附近应有足够的接地线 |

### 7.3 机械安装注意事项

| 项目 | 说明 |
|------|------|
| **轮子方向** | 麦轮安装方向要正确，呈X型或O型 |
| **编码器对齐** | 确保编码器轴与电机轴对齐 |
| **走线固定** | 运动部件附近的线缆要固定好 |
| **防水** | 室外使用需做好防水措施 |

### 7.4 调试建议

1. **分步测试**
   - 先测试电源系统
   - 再测试单个电机驱动
   - 然后测试编码器反馈
   - 最后测试整体系统

2. **方向校准**
   - 给正向速度，观察轮子转向
   - 不正确则修改 `MOTOR_X_REVERSE`
   - 观察编码器反馈方向
   - 不正确则修改 `ENCODER_X_REVERSE`

3. **检查清单**
   - [ ] 电源电压正确
   - [ ] 所有GND已连接
   - [ ] 电机转向正确
   - [ ] 编码器反馈正常
   - [ ] 串口通信正常
   - [ ] IMU数据正常
